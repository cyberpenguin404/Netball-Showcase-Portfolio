# Netball - Portfolio piece showcasing usage of Unity NetCode
**This project was built on top of a single-player starter template provided by DAE.** 

The starter template provided the single-player gameplay (player movement, ball mechanics, basic scene setup). Everything related to multiplayer (Netcode synchronization, the lobby/matchmaking layer, PlayFab login, the ASP.NET Core backend, and the Azure SQL database) was built entirely by me for the final assignment.

See [pepijnvanhumbeeck.be](https://www.pepijnvanhumbeeck.be/) for a more detailed description of the project.
